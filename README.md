# Fitness-Tracker
A backend Fitness Tracker Web API built with ASP.NET MVC, following a 3-tier architecture (DAL–BLL–API) that enables users to manage workouts, goals, and progress efficiently. It includes role-based authentication and authorization, SMTP email notifications, and token-based security. The project uses Entity Framework, AutoMapper, and the Repository pattern with SQL Server as the database, tested through Postman for all CRUD and API operations.
